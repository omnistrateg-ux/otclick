# Источники данных — Otclick Employer Acquisition Engine

## Discovery Sources

### hh.ru API (основной)

**Что даёт**: компании, вакансии, контактные данные HR, интенсивность найма.

**Endpoints**:
- `GET /vacancies` — поиск вакансий по параметрам (отрасль, город, ключевые слова)
- `GET /employers/{id}` — профиль работодателя
- `GET /employers/{id}/vacancies` — все вакансии работодателя

**Ключевые параметры поиска**:
- `text`: "кассир OR продавец OR грузчик OR комплектовщик OR разнорабочий"
- `area`: код региона (1 = Москва, 2 = СПб, ...)
- `industry`: код отрасли
- `employer_type`: "company"
- `per_page`: 100
- `order_by`: "publication_time"

**Что извлекаем из вакансии**:
- employer.id, employer.name, employer.url
- контакты (если указаны): имя, email, телефон
- зарплатная вилка (для оценки сегмента)
- schedule, employment_type
- description (для pain point extraction через LLM)

**Что извлекаем из профиля работодателя**:
- industries[], area, site_url
- open_vacancies (количество активных вакансий)
- description

**Rate limits**: 5 req/sec с токеном, 2 req/sec без.

**Авторизация**: OAuth2 bearer token. Получение: https://dev.hh.ru/

### Avito (дополнительный)

**Что даёт**: компании с вакансиями (особенно малый бизнес, который не на hh.ru).

**Метод**: headless browser (Playwright) → парсинг страниц категории "Вакансии".

**URL-паттерн**: `https://www.avito.ru/{city}/vakansii?q={query}`

**Что извлекаем**:
- Название компании (из объявления)
- Описание вакансии
- Телефон (если указан)
- Город, район

**Ограничения**:
- Нет API, только парсинг
- Avito активно блокирует ботов — нужны прокси и ротация
- Контактные данные часто скрыты
- Использовать для discovery, не для enrichment

---

### 2GIS API

**Что даёт**: компании по категории + город, телефоны, адреса, филиалы.

**Использование**: discovery компаний в конкретном городе по категории.

**Пример запроса**: "рестораны Москва", "строительные компании Казань"

**Что извлекаем**:
- Название, адрес, телефон, сайт
- Категория (для определения IndustrySegment)
- Количество филиалов
- Часы работы (косвенный сигнал масштаба)

---

### CSV-импорт (ручной)

**Сценарии**:
- Список компаний с выставки/конференции
- Партнёрский список от интеграторов
- Ручная выгрузка из CRM / Excel

**Формат**:
```csv
company_name,domain,city,industry,contact_name,contact_email,contact_phone,source
"ООО Лента",lenta.com,Москва,retail,"Иванова Мария",hr@lenta.com,+79001234567,выставка_hr_2025
```

**Обязательные поля**: company_name
**Опциональные**: всё остальное

## Contact Enrichment Sources

### hh.ru (вакансии)

Контакты HR/рекрутера часто указаны в вакансии:
- Имя контакта
- Email (рабочий)
- Телефон

Это основной и самый качественный источник контактов.

### Hunter.io

**Что даёт**: email по домену компании.

**API**: `GET https://api.hunter.io/v2/domain-search?domain={domain}`

**Возвращает**:
- Список email'ов сотрудников
- Должность, имя
- Паттерн email'ов компании (firstname@, f.lastname@, ...)
- Confidence score

**Стоимость**: от $0.01/email, 25 бесплатных поисков/месяц.

### Парсинг сайта компании

**Страницы для парсинга**:
- /contacts, /kontakty, /about
- /career, /vacancy, /vakansii, /jobs

**Что извлекаем**:
- Email (regex + LLM для классификации: общий vs HR vs директор)
- Телефон
- Форма обратной связи (если нет прямого email)

### LinkedIn (на будущее)

Не реализуем в v1. План:
- Использовать для ручного enrichment
- Возможна интеграция через Apollo.io API
- Compliance-риски при автоматизации
